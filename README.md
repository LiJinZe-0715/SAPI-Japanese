# VOICEVOX 日语语音（SAPI5）使用手册

这个程序把 [VOICEVOX](https://voicevox.hiroshiba.jp/) 的日语声音装成 Windows 的**系统语音**。装好之后，
Chrome、Edge 的网页朗读，Windows 讲述人，以及其他支持 Windows 语音的软件，都能在语音列表里直接选用
「俊达萌 / 普通 · 孩子气高音」这样的日语声音。

- 不需要打开 VOICEVOX 编辑器，也不需要联网，声音在本机合成
- 语音名称会按系统语言显示成中文、日文或英文

## 系统要求

- Windows 10 或 Windows 11，**64 位**
- 安装时需要管理员权限
- 磁盘空间：标准版约 200 MB，完整版约 1.8 GB
- [Microsoft VC++ 2015-2022 运行库（x64）](https://aka.ms/vs/17/release/vc_redist.x64.exe)。
  大多数电脑已经装过；如果装完没有声音，先装一次它

## 选择安装包

安装包有三种，区别只在于带了哪些声音：

| 安装包 | 包含的声音 | 大小 |
|---|---|---|
| 标准版（generic） | 通用女声 1/2/3、通用男声 1/2/3，共 6 个 | 约 193 MB |
| 经典版（classic） | 四国めたん、ずんだもん、春日部つむぎ、雨晴はう，4 个角色共 10 种风格 | 约 178 MB |
| 完整版（all） | 52 个角色，共 136 种声音 | 约 1.8 GB |

只想要几个好用的声音选标准版；想要 VOICEVOX 的人气角色选经典版。全部声音的中日英名称对照见
[`docs/voices.html`](docs/voices.html)，可以搜索。

同一时间只能装一种。装另一种安装包会**替换**掉当前这套声音。

## 安装

1. 下载 `VoicevoxSapiSetup.exe`，双击运行
2. 如果出现「Windows 已保护你的电脑」，点「更多信息」→「仍要运行」（安装包没有数字签名，所以会有这个提示）
3. 在用户账户控制（UAC）窗口点「是」
4. 等几秒，出现「安装完成」
5. **关掉并重新打开浏览器**，新声音才会出现在它的列表里

安装过程不需要联网，也不会出现进度窗口，只在最后弹出结果。

## 在哪里使用

| 位置 | 怎么找到 |
|---|---|
| Chrome / Edge 的网页朗读 | 网页或朗读扩展里选择语音时，列表里会有日语（ja-JP）的新声音 |
| Windows 讲述人 | 设置 → 辅助功能 → 讲述人 → 讲述人的语音 |
| Windows 语音设置 | 设置 → 时间和语言 → 语音 |
| 传统语音控制面板 | 控制面板 → 语音识别 → 文本到语音 |
| 其他朗读软件（如 Balabolka） | 在软件的语音列表里选择 |

这些声音只会读**日语**。把中文或英文交给它，读出来会是日语式的发音。

### 语音名称怎么看

列表里的一条声音长这样：

```
俊达萌 / 普通 · 孩子气高音
```

三段分别是 **角色 / 风格 · 音质**。同一个角色可能有好几种风格（普通、撒娇、耳语……），各算一条。
系统语言是日文时显示「ずんだもん / ノーマル · 子供っぽい高めの声」，英文时显示
「Zundamon / Normal · Childish and high」，改系统语言后不用重新安装。

中文名不是官方译名，是中文圈的常用叫法，仅供辨认。

### 语速、音调和音量

在使用它的软件里调就行，比如朗读扩展的语速滑块、讲述人的语速设置、网页里的 `rate` / `pitch` /
`volume` 参数。可调的范围：

- 语速：0.5 倍到 2 倍
- 音调：可以调高调低，但幅度不大（再大声音会失真）
- 音量：从静音到正常音量

## 只显示我想要的声音

装了很多声音、列表太长时，可以只保留其中几条。声音文件不会被删除，只是不在列表里显示。

1. 在开始菜单搜索「记事本」，右键 →「以管理员身份运行」
2. 在记事本里打开 `C:\ProgramData\VoicevoxSapi\voices.txt`
3. 一行写一个想保留的声音。可以写角色名（中文、日文、英文都可以），也可以写声音编号：

   ```
   # 井号开头的行是注释
   俊达萌
   四国めたん
   Kasukabe Tsumugi
   ```

   写角色名会保留这个角色的所有风格。声音编号可以在 [`docs/voices.html`](docs/voices.html) 里查到。
4. 保存。然后在开始菜单搜索「终端」或「命令提示符」，右键 →「以管理员身份运行」，执行：

   ```
   "C:\Program Files\VoicevoxSapi\voicevox-sapi-setup.exe" install
   ```

5. 重新打开浏览器

几点说明：

- 想恢复全部声音，把文件里的内容删光（或只写一行 `*`），再执行第 4 步
- 也可以给声音换个显示名：写成 `编号 = 另一个编号`，就会用后一个声音的名字显示前一个声音。
  标准版里的「女声3」就是这样来的，它实际用的是女声 6 的声音
- 如果写的名字一个都对不上（比如打错字），程序会忽略这个文件、显示全部声音，而不是一个都不显示
- 重新安装或升级时，你改过的 `voices.txt` 会保留

## 升级

直接运行新版本的安装包即可，不需要先卸载。浏览器开着也可以装；新版本对之后新打开的浏览器生效，
正在运行的浏览器重启后生效。少数情况下会提示需要重启电脑才能完成替换。

## 卸载

设置 → 应用 → 已安装的应用（Windows 10 是「应用和功能」）→ 「VOICEVOX 音声 (SAPI5)」→ 卸载。

卸载会删除所有声音和程序文件。卸载后重启浏览器，声音就会从列表里消失。如果浏览器还开着，部分文件
会在下次开机时删除，卸载完成的提示里会说明。

## 常见问题

**装完了，浏览器里看不到新声音。**
浏览器只在启动时读取一次语音列表，需要**完全关闭**后重新打开（包括后台运行的进程，可以在任务栏
右下角的托盘图标里退出）。另外确认网页或扩展的语言筛选里包含日语。

**列表里有声音，但选了没有声音。**
1. 第一次使用某个声音时要载入模型，需要等几秒（标准版约 8 秒），之后就快了
2. 安装一次 [VC++ 运行库（x64）](https://aka.ms/vs/17/release/vc_redist.x64.exe)，然后重启浏览器
3. 还是不行，打开 `C:\ProgramData\VoicevoxSapi\logs\voicevox-sapi.log`，看最后几行有没有
   `failed` 字样，反馈问题时请附上这个文件

**一句话里有几句话读不出来。**
个别句子合成失败时会跳过，其余照常朗读。日志里会记录是哪一句，欢迎反馈。

**安装时提示「安装包已损坏」。**
下载不完整，请重新下载。

**安装时提示「无法写入 … set ACL on … (error 5)」。**
安装程序在设置文件夹权限时被系统或安全软件拦截了。把安装包移到「下载」文件夹再运行通常就能解决；
如果装了第三方安全软件，可以暂时允许它后再试。

**32 位的软件里为什么看不到这些声音？**
这些声音只支持 64 位程序。现在的 Chrome、Edge 和讲述人都是 64 位的。

**能用中文或英文朗读吗？**
不能，这些都是日语声音。

**会上传我朗读的内容吗？**
不会。所有声音都在本机合成，不联网。

## 已知限制

- 只能读日语，只支持 64 位程序
- 一段话按句子朗读，第一句开始前有短暂等待；很长又没有标点的句子，等待会更久
- 网页朗读中「读到哪里高亮到哪里」只能精确到句子，不能精确到词
- 安装包没有数字签名，首次运行会出现 SmartScreen 提示
- 没有开始菜单项，也不会自动更新

## 声音的使用条款

本程序附带的声音来自 VOICEVOX。各角色的声音有各自的使用条款，用于视频、直播、发布作品等用途时，
请先阅读 [VOICEVOX 音声モデル利用規約](https://github.com/VOICEVOX/voicevox_vvm/blob/main/README.md)
和各角色的规约，并按要求标注署名（例如「VOICEVOX:ずんだもん」）。
