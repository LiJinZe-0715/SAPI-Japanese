# VOICEVOX 日语语音（SAPI5）

把 [VOICEVOX](https://voicevox.hiroshiba.jp/) 的日语声音注册成 Windows 系统语音。装好之后，Chrome / Edge
的网页朗读、Windows 讲述人、Balabolka 等支持 SAPI5 的软件，都能在语音列表里直接选用日语声音。

声音在本机合成，不需要打开 VOICEVOX 编辑器，也不需要联网。

## 系统要求

- Windows 10 / 11，**64 位**；只支持 64 位程序
- 安装需要管理员权限
- [Microsoft VC++ 2015-2022 运行库（x64）](https://aka.ms/vs/17/release/vc_redist.x64.exe)。
  多数电脑已装过；**没有它语音引擎根本加载不起来**，安装程序会在动手之前先检查并提示，不会装一半再失败
- 磁盘空间：标准版约 200 MB，完整版约 1.8 GB

## 选择安装包

| 安装包 | 包含的声音 | 大小 |
|---|---|---|
| 标准版 `generic` | 通用女声 1-3、通用男声 1-3，共 6 个 | 约 193 MB |
| 经典版 `classic` | 四国めたん、ずんだもん、春日部つむぎ、雨晴はう，4 个角色 / 10 种风格 | 约 178 MB |
| 完整版 `all` | 53 个角色 / 137 种声音 | 约 1.8 GB |

一次只能装一种，安装另一种会替换当前这套声音。

## 安装

1. 双击 `VoicevoxSapiSetup.exe`
2. 首次运行会出现 SmartScreen 提示（安装包未签名）：「更多信息」→「仍要运行」
3. UAC 点「是」，等几秒，出现「安装完成」
4. **完全关闭并重新打开浏览器**，新声音才会出现在列表里

程序文件在 `C:\Program Files\VoicevoxSapi`，运行时、词典和模型在 `C:\ProgramData\VoicevoxSapi`。
安装不联网，也没有进度窗口，只在结束时弹出结果。

安装同时注册一个登录时启动的计划任务 `VoicevoxSapiServer`：常驻引擎预先加载模型，让第一句话
从约 13 秒降到半秒左右。它由任务计划程序启动，因此不在浏览器的进程树里，浏览器重启不会把它
带走；空闲 30 分钟自动退出，把约 300 MB 内存还给系统，下一次朗读时由 DLL 按需唤醒，不需要等
下次登录。不想要这个常驻进程，可以在任务计划程序里禁用或删除该任务：功能不受影响，只是每个
新进程的第一句话要等十几秒。

## 在哪里使用

| 场景 | 位置 |
|---|---|
| Chrome / Edge 网页朗读 | 网页或朗读扩展的语音列表，日语（ja-JP）分组 |
| Windows 讲述人 | 设置 → 辅助功能 → 讲述人 → 讲述人的语音 |
| Windows 语音设置 | 设置 → 时间和语言 → 语音 |
| 传统控制面板 | 控制面板 → 语音识别 → 文本到语音 |
| 其他朗读软件 | 各自的语音列表 |

语音名是 **角色 / 风格 · 音质** 三段，例如「俊达萌 / 普通 · 孩子气高音」。同一角色可能有多种风格，
各算一条。名称随系统语言切换成中文、日文或英文，改系统语言不需要重装。中文名是圈内常用叫法，
不是官方译名，仅供辨认。

这些声音**只会读日语**，把中文或英文交给它会读成日语音。语速（约 0.5–2 倍）、音调和音量在调用它的
软件里调整。

## 只显示想要的语音

编辑 `C:\ProgramData\VoicevoxSapi\voices.txt`（需要管理员权限），一行写一个：

```
# 井号开头是注释
俊达萌
四国めたん
Kasukabe Tsumugi
```

写角色名会保留该角色的全部风格，中文、日文、英文都可以；也可以写 style id。写成 `10006 = 10004`
可以给声音换个显示名（标准版里的「女声3」就是这样来的）。声音文件不会被删除，只是不显示。

保存后以管理员身份执行：

```
"C:\Program Files\VoicevoxSapi\voicevox-sapi-setup.exe" install
```

然后重启浏览器。清空文件或写一行 `*` 可恢复全部。名字一个都对不上时，程序会忽略这个文件并显示
所有声音，而不是一个都不显示。升级不会覆盖你改过的 `voices.txt`。

## 升级与卸载

- **升级**：直接运行新安装包，不用先卸载。安装过程会停掉常驻引擎再重新拉起，所以新版本立刻生效；
  已打开的浏览器重启后生效，极少数情况会提示重启电脑
- **卸载**：设置 → 应用 → 已安装的应用 →「VOICEVOX 音声 (SAPI5)」→ 卸载，之后重启浏览器

卸载会删除声音、程序文件和上面那个计划任务，之后重启浏览器。若浏览器还占用着文件，剩余部分
会在下次开机时删除，提示里会说明。
命令行工具 `voicevox-sapi-setup.exe` 也提供 `install` / `uninstall` / `status` 三个子命令。

## 常见问题

**浏览器里看不到新声音。** 浏览器只在启动时读取一次语音列表，要完全退出（包括托盘里的后台进程）
再打开；另外确认网页或扩展的语言筛选包含日语。

**有声音但选了不出声。** 首次载入模型要等几秒；装一次
[VC++ 运行库（x64）](https://aka.ms/vs/17/release/vc_redist.x64.exe) 并重启浏览器；仍不行就看
`C:\ProgramData\VoicevoxSapi\logs\voicevox-sapi.log` 最后几行有没有 `failed`，反馈问题时请附上。

**一句话里有几句没读出来。** 个别句子合成失败会跳过，其余照常朗读，日志里会记录是哪一句。

**提示「安装包已损坏」。** 下载不完整，重新下载。

**提示无法设置文件夹权限（error 5）。** 安装程序设 ACL 时被系统或安全软件拦了。把安装包移到
「下载」文件夹再运行通常能解决。

## 已知限制

- 只读日语，只支持 64 位程序
- 按句朗读，第一句前有短暂等待；很长又没有标点的句子等待更久
- 网页朗读的跟读高亮只能精确到句子，不能精确到词
- 安装包没有数字签名，首次运行有 SmartScreen 提示
- 没有开始菜单项，也不会自动更新

## 声音的使用条款

附带的声音来自 VOICEVOX，各角色有各自的使用条款。用于视频、直播、发布作品前请先阅读
[VOICEVOX 音声モデル利用規約](https://github.com/VOICEVOX/voicevox_vvm/blob/main/README.md) 和各角色
规约，并按要求标注署名（例如「VOICEVOX:ずんだもん」）。

## 从源码构建

需要 Visual Studio 2022（含 C++ 工作负载）、Windows SDK、CMake、Ninja，以及
[VOICEVOX core](https://github.com/VOICEVOX/voicevox_core/releases) 的 Windows x64 包
（含 `c_api`、`onnxruntime`、`dict`、`models\vvms\*.vvm`）。

```
build.bat <voicevox_core 目录>
package.bat generic <voicevox_core 目录>
```

第一条只编译，第二条编译并打包（`generic` 可换成 `classic` 或 `all`，且内部会自行调用
`build.bat`，平时只用第二条即可）。产物是
`build\VoicevoxSapi.dll` 和 `dist\VoicevoxSapiSetup.exe`。打包前会校验
`src\catalog_table.inc` 与磁盘上的模型包是否一致；模型包版本变了，先用
`build\voicevox-model-metas.exe <vvms目录> --cpp` 重新生成该表。
